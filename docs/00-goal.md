# 프로젝트 목표

## 한 줄 목표
동료 개발자 2인이 함께 작은 제품을 실제로 출시해보며 협업, 배포, 운영의 전체 흐름을 경험한다.

## 이 프로젝트에서 얻고 싶은 것
- 아이템 선정부터 출시까지의 전체 사이클 경험
- Git 기반 협업, 이슈 관리, 코드 리뷰 경험
- MVP 정의와 범위 조절 경험
- 실제 배포 및 사용자 피드백 반영 경험

## 성공 기준
다음 중 대부분을 달성하면 성공으로 본다.
- 아이템 1개를 선정했다.
- MVP 범위를 문서로 합의했다.
- 실제로 배포 가능한 버전을 만들었다.
- 외부 사용자 또는 지인에게 공유했다.
- 최소 1회 이상 수정 배포했다.

## 비목표
- 처음부터 수익화
- 대규모 서비스 구축
- 지나치게 복잡한 아키텍처 설계
- 기능을 많이 넣는 것 자체

## 기간 제안
- 목표 기간: 6~8주
- 너무 길어지면 동력이 떨어지므로 기간을 먼저 고정한다.
